# ChatGPT-Review-Analysis

📌 Overview

This project focuses on analyzing ChatGPT customer reviews using Python and Natural Language Processing (NLP) techniques.
The objective was to understand customer sentiment, identify frequently mentioned keywords, and extract meaningful insights from textual review data.

Using sentiment analysis and data visualization, the project transforms raw review text into actionable business intelligence.

🎯 Objectives

✅ Analyze overall customer sentiment toward ChatGPT

✅ Measure sentiment polarity and subjectivity

✅ Identify common positive and negative keywords

✅ Compare sentiment with user ratings

✅ Discover customer satisfaction trends

📂 Dataset Features

The dataset includes:

📝 Review Text

⭐ User Ratings

📅 Review Dates

📊 Additional review metadata


🧹 Data Preparation


The dataset was cleaned and preprocessed using Python:

✔ Removed missing and duplicate values

✔ Standardized column names

✔ Converted ratings into numeric format

✔ Converted date columns into datetime format

✔ Cleaned and processed review text for NLP analysis


😊 Sentiment Analysis


Sentiment analysis was performed using the TextBlob library.


📌 Metrics Used


Polarity → Determines whether reviews are Positive, Neutral, or Negative


Subjectivity → Measures how opinion-based the reviews are
